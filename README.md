# MNTN Landing Page
This is a responsive landing page created to showcase my protfolio. Built with modern technologies, this landing page combines smooth animations, high-quality visuals, and a clean design to create an immersive experience. Feel free to contact me if you'd like to create something similar for your brand or project!

# Features
- Responsive Design: Adapts to various screen sizes, ensuring a seamless experience across devices.
- Smooth Animations: Enhanced with GSAP animations for engaging transitions.
- Scroll Indicator: A unique scroll indicator shows the current section of the page.
- Stylish Hero Section: High-quality hero image and text overlay to capture visitors` attantion.
- Gallery Section: Organized gallery layout with alternating image and text blocks for an  engaging storytelling.

# Getting Starter
To view or modify the code on your local machine:
1. Clone the repository:
    ```
    git colne https://github.com/DanV-development/mntn_landing.git
    ```
2. Open the `index.html` file in your browser.

# Installation of Dependencies
For animations, this project uses GSAP libraries. You can add them to tyour project by including the followng:
```JS
<script src="libs/gsap/gsap.min.js" defer></script>
<script src="libs/gsap/ScrollSmoother.min.js" defer></script>
<script src="libs/gsap/ScrollTrigger.min.js" defer></script>
```
